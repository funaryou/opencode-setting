# GitHub MCP Skill

Use this skill when the user asks about GitHub repositories, pull requests, issues, commits, branches, releases, or Actions workflows.

## Workflow

1. Prefer GitHub MCP tools over generic web browsing for repository-specific facts.
2. When summarizing PRs/issues, include concrete IDs, status, and next actions.
3. For code changes, reference affected files and explain risk areas.
4. If write operations are requested (comment, merge, close, label), confirm intent before execution.

## Output style

- Keep summaries concise and decision-oriented.
- Include direct links when available.
- Distinguish facts from assumptions.
