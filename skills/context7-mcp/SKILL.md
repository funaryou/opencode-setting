# Context7 MCP Skill

Use this skill when the user needs current API usage, setup steps, migration notes, or framework/library behavior.

## Workflow

1. Resolve the right library/project first.
2. Pull focused docs for the exact question instead of broad dumps.
3. Prefer version-aware guidance when version is known.
4. Return implementation-ready steps and minimal examples.

## Output style

- Cite the doc source/path when possible.
- Separate official behavior from best-practice suggestions.
- Call out version assumptions explicitly.
