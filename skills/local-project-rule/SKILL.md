# 絶対ルール: プロジェクトローカルの .opencode を編集する

もしユーザーから「skillsに記しておいてくれ」や「ルールにしておいて」「テンプレとして残して」など、
**設定や知見を保存するよう指示された場合は、必ず以下のルールに従うこと。**

## 編集対象

**カレントプロジェクトの `.opencode/` ディレクトリ** を編集する。

- パス: `./.opencode/` （プロジェクトルートからの相対パス）
- 例: `/Users/fur-dev/projects/funa-git/workspace/projects/my-project/Shuukatu/.opencode/`

## 編集しないもの

- **`~/.config/opencode/` （グローバル設定）は編集しない**
- グローバル設定は opencode 自体の設定変更や、スキルの追加インストール時のみ使う

## 理由

プロジェクトの設定や知見はそのプロジェクトに閉じて管理する。
グローバル設定は全プロジェクトに影響してしまうため、特定プロジェクトのルールはプロジェクトローカルに書く。

## 例外

このルール自体の変更や、opencode の設定ファイル（opencode.json など）の編集を指示された場合は
状況に応じて判断すること。

---

**これは絶対。違反したらユーザーに強く指摘される。**
