# Notion MCP Skill

Use this skill when the user asks to read, create, update, or organize content in Notion pages and databases.

## Workflow

1. Identify target workspace/page/database first.
2. For edits, restate the intended change before applying.
3. Preserve existing structure unless the user asks for reorganization.
4. When generating content, format with clear headings, bullet lists, and action items.

## Output style

- Provide a short summary of what changed.
- Mention page/database titles explicitly.
- Flag uncertain mappings (for example, similar page names) before writing.
